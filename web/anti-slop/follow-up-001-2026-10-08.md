# Anti-slop follow-up

Date: 2026-10-08
Approved scope: findings 1-15 from `audit-001-2026-10-08.md`.

## Implemented

1. Mobile navigation now has a visible text label, includes all primary and secondary destinations in the sheet, and keeps the account link visible outside the sheet; the duplicate desktop row is hidden at the mobile breakpoint. Listening is present in the sheet when configured.
2. Replaced known light muted text colors with darker tokens. Computed examples against white/light surfaces: `#4f5f73` on `#FFFFFF` = 6.53:1; `#52667e` on white = above 5:1; story-slide text colors on their surfaces = above 7:1.
3. Added a single `ค้นหา` action alongside status and category selectors. It submits the same query form, serializes query/category/status to URL parameters, and shows pending feedback.
4. Focus indicators use a solid `#315f97` outline. The search input is contained by a visible focus-within ring; other focusable controls have explicit outlines. The contrast of the solid outline against white is computed above 6:1.
5. Removed the unsupported “NOVELREAD PICKS” carousel section, which had labeled the first API rows as editorial picks without a source. The homepage now shows the actual latest list and category shelves.
6. Removed the full-page radial background glow. Current page paper color is flat; book cover fallbacks remain styled as covers, not ambient gradients.
7. Documented why book/navigation icons are used. Empty-state sparkle decorative marker was removed from shared empty states; category/page identity no longer depends on decorative star graphics.
8. Recorded the Thai/Latin font rationale and removed tracked uppercase hero eyebrow styling from the homepage. DM Sans stays for Latin wordmark; Noto Sans Thai is the reading face.
9. Removed arrow suffixes from routine search/navigation actions, retaining them only where a directional reading action or chapter navigation is materially useful.
10. Category badges now use a compact rectangular label treatment; status remains a distinct status value rather than being promoted as decoration.
11. Removed backdrop blur from the sticky header and reader toolbar; both retain solid surfaces for legibility.
12. Homepage section entrance no longer fades/rises on load. Short interaction transitions remain and respect reduced motion.
13. Replaced the unsupported feature carousel with latest-first browsing. Categories remain separate shelves because they group real catalog content and are omitted when too small to be useful.
14. Added Novelread visual identity rationale and a bounded blue/paper palette with cover art as the content-led motif.
15. Recorded one-line reasons for palette, typography, navigation, cards, spacing/rhythm, icons, and motion in the root `UI-REDESIGN.md`.
