# Novelread UI audit 002

Date: 2026-10-08  
Mode: After (session override)  
Scope: Live mobile homepage at `http://127.0.0.1:3000/`, homepage source, and a visual comparison with [MyNovel](https://mynovel.co/).

## Direction read

Reading this as: Thai novel discovery and reading for Thai readers, with a content-led editorial book-catalogue style inspired by MyNovel's section hierarchy, while retaining Novelread's paper-white, muted-blue identity. ENERGY 2 / RHYTHM 2 / MOTION 1, as recorded in `UI-REDESIGN.md`.

MyNovel is used as a reference for content hierarchy and browsing patterns, not as a visual template. No new art or promotional assets are included in these findings.

## Findings

16. **MEDIUM — R-01:** The mobile fallback covers repeat the same navy gradient and orbit-line graphic across many stories, and the existing rationale does not explain this treatment; because covers dominate each card, the repeated effect makes the catalogue feel like a set of placeholders.

17. **LOW — R-05:** The homepage presents all 24 latest stories in the same two-column mobile grid and then repeats them in genre grids, so the page has little section rhythm or editorial hierarchy compared with the distinct content rows on MyNovel.

18. **LOW — R-20:** The visible homepage is dominated by generic fallback covers and test-fixture titles such as `[redesign verification]`, so changing the Novelread wordmark would leave little product-specific visual identity in the main content.

## Evidence

- The live Novelread page's accessibility tree reports 24 stories in “อัปเดตล่าสุด”, followed by genre sections that repeat the same story links; the mobile screenshot shows identical fallback-cover styling across the first cards.
- The live MyNovel homepage has a promotional banner, an author-update row, horizontal latest-story and comic shelves with cover art, and a ranked list. The comparison supports hierarchy and browsing rhythm only; it does not imply Novelread should add unsupported promotions, rankings, or metrics.
- `UI-REDESIGN.md` already records the user's chosen paper-white/muted-blue palette, compact catalog, and dials. The issues above concern how that direction currently appears with this local dataset.

## Scope note

The browser currently contains development/test novels, including many titles explicitly marked as redesign verification. This audit does not recommend deleting or changing stored stories. Any UI change should preserve the records and use existing real cover images where available; ask before creating new visual assets.
