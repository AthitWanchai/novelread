# Novelread 1.0 — อ่าน เขียน และฟังนิยาย

เวอร์ชัน 1.0 เป็นเว็บอ่านและเขียนนิยายที่รันบนเครื่องตัวเอง มีบัญชีผู้ใช้และฐานข้อมูล SQLite เก็บข้อมูลข้ามการปิดโปรแกรม

หน้าตาใหม่ใช้พื้นขาว–เทาอ่อนและน้ำเงินหม่น มีเมนูด้านล่างบนมือถือ แท็บชั้นหนังสือ/สารบัญ และแผงตั้งค่าการอ่าน พร้อมการเคลื่อนไหวสั้น ๆ ที่รองรับการลดการเคลื่อนไหว ดูผลตรวจใน `UI-REDESIGN.md`

## ฟีเจอร์ 1.0

- ค้นเรื่องด้วยชื่อ นามปากกา และแท็ก กรองหมวดและสถานะ
- รายละเอียดเรื่อง ปก คำโปรย เรต สารบัญ และหน้าอ่านก่อนหน้า/ถัดไป
- ปรับขนาดอักษรและพื้นหลังสว่าง/กระดาษ/มืด
- สมัครบัญชี เข้าสู่ระบบ ออกจากระบบ และแก้ชื่อที่แสดง พร้อมกลับไปทำสิ่งที่ค้างไว้
- ชั้นหนังสือแยกเรื่องที่ติดตามและประวัติอ่าน พร้อมปุ่มอ่านต่อที่จำย่อหน้าและตัวอักษร แม้เปลี่ยนขนาดตัวอักษร
- เลือกรับช่วงตำแหน่งอ่านก่อนสมัครเข้าบัญชีได้
- อัปโหลดปก PNG/JPEG/WebP ไม่เกิน 5 MB หรือใช้ลิงก์รูป พร้อมปกชื่อเรื่องเมื่อรูปเปิดไม่ได้
- นักเขียนสร้าง/แก้เรื่อง เพิ่ม/แก้ตอน บันทึกร่าง เผยแพร่ และเรียงตอน
- สำรองข้อความระหว่างเขียนในเบราว์เซอร์; ต้องกดบันทึกเพื่อเก็บลงฐานข้อมูล
- ฟังตอนที่เขียนผ่านเครื่องเสียงเดิม และเปิดเครื่องฟังจากลิงก์ที่ `/listen.html`

เริ่มจากหน้าแรก → สมัครบัญชี → เริ่มเขียน → สร้างนิยาย → เพิ่มตอน → เผยแพร่ตอน จากนั้นเรื่องจะปรากฏในหน้าค้นพบ ผู้อ่านไม่ต้องสมัครบัญชีเพื่ออ่านตอนที่เผยแพร่

### ข้อมูลและการสำรอง

ข้อมูลบัญชี นิยาย ตอน และชั้นหนังสืออยู่ใน `data/novelread.db` ส่วนรูปปกที่อัปโหลดอยู่ใน `data/covers/` ซึ่งไม่ถูกนำขึ้น Git รหัสผ่านเก็บเป็นค่าแฮช ปิดโปรแกรมก่อนคัดลอกโฟลเดอร์ `data` ทั้งโฟลเดอร์ไปสำรอง และคัดลอกกลับเมื่อต้องการกู้คืน อย่าลบโฟลเดอร์นี้เมื่อต้องการอัปเดตโปรแกรม

หน้าแรกเริ่มว่าง ไม่มีเรื่องหรือจำนวนผู้อ่านจำลอง การเผยแพร่หมายถึงแสดงเรื่องในโปรแกรมบนเครื่องนี้ โปรแกรมเปิดเฉพาะ `127.0.0.1` ยังไม่ได้เปิดบริการบนอินเทอร์เน็ต เวอร์ชันนี้ยังไม่มีขายตอน เติมเงิน ความคิดเห็น และระบบกู้รหัสผ่าน การสร้างเสียงต้องเชื่อมต่ออินเทอร์เน็ตและขึ้นกับบริการเสียงที่ตั้งค่าไว้

## เครื่องฟังนิยายจากลิงก์

ดึงเนื้อหานิยายจากหน้าเว็บ แกะเอาเฉพาะเนื้อเรื่อง แล้วอ่านออกเสียงด้วยเสียง Neural
ทำงานบนเครื่องตัวเอง ไม่ต้องสมัครสมาชิก ไม่ต้องมี API key

## ใช้ทำอะไร

วางลิงก์ตอนนิยาย → กดปุ่มเดียว → ฟังได้เลย พร้อมไฮไลต์ตามที่กำลังอ่าน
จำตำแหน่งที่ค้างไว้ และเก็บเสียงที่สร้างแล้วไว้ในเครื่อง ฟังซ้ำไม่ต้องโหลดใหม่

## เริ่มใช้งาน

ต้องมี Python 3.10 ขึ้นไปในเครื่อง จากนั้นดับเบิลคลิก:

```
start.bat
```

ครั้งแรกจะติดตั้ง Python และ Node.js packages ที่จำเป็นให้เอง จากนั้นรัน API ของแอปบน `127.0.0.1:8756` และเปิดเว็บ Next.js ที่ `http://127.0.0.1:3000` หน้าเว็บหลักใช้ Next.js; API ฝั่ง Python ยังเก็บข้อมูลและให้บริการอ่าน/เขียน รวมถึงเครื่องฟังลิงก์ที่ `/listen.html` ระหว่างที่ยังย้ายเครื่องมือนี้ไม่เสร็จ การเปิดพอร์ต API โดยตรงจะพาไปหน้า Next.js

ถ้าอยากสั่งเอง:

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python server.py
```

เปิดอีกหน้าต่าง terminal เพื่อติดตั้งและรัน frontend:

```bash
npm install
npm run dev
```

เปิด `http://127.0.0.1:3000` เพื่อใช้เว็บ Next.js ซึ่งดึงข้อมูลจาก API ที่พอร์ต `8756` ต้องมี Node.js 20.9 ขึ้นไป

## โครงสร้าง

```
server.py          เซิร์ฟเวอร์ + API
lib/fetcher.py     ดึงหน้าเว็บ (ทำฝั่งเซิร์ฟเวอร์เพราะเบราว์เซอร์ติด CORS)
lib/extractor.py   แกะเนื้อเรื่องออกจากโฆษณาและเมนู
lib/normalize.py   เกลาข้อความก่อนอ่าน เช่น แปลงเลขอารบิกเป็นคำอ่านไทย
lib/tts/           ชั้น adapter ของเครื่องเสียง สลับได้โดยไม่ต้องแก้โค้ดส่วนอื่น
public/            หน้าเว็บ
sites.json         กฎการแกะเนื้อหาแยกตามเว็บ
pronounce.json     พจนานุกรมคำอ่าน เติมเองได้
config.json        ตั้งค่าเสียง ความเร็ว พอร์ต
```

## ปรับให้เข้ากับเว็บที่อ่านประจำ

ถ้าเว็บไหนแกะเนื้อหาได้ไม่สะอาด (มีเมนูหรือโฆษณาปน) เพิ่มกฎลงใน `sites.json`:

```json
{
  "ชื่อเว็บ.com": {
    "title": "h1.chapter-title",
    "content": "div.chapter-content",
    "remove": [".ads", ".comment"],
    "next": "a.next-chapter"
  }
}
```

ถ้าไม่ได้ตั้งกฎไว้ ระบบจะใช้ตัวแกะอัตโนมัติ (trafilatura) ซึ่งใช้ได้กับเว็บส่วนใหญ่อยู่แล้ว

## แก้คำที่อ่านผิด

เจอคำไหนอ่านเพี้ยน โดยเฉพาะชื่อตัวละครนิยายแปล ใส่ลงใน `pronounce.json`:

```json
{
  "เย่เฉิน": "เย่ เฉิน",
  "Lv.": "เลเวล "
}
```

## เครื่องเสียง

**`edge` (ค่าเริ่มต้น)** — เสียง Neural ของ Microsoft ผ่านช่องทางที่ Edge ใช้อ่านออกเสียงหน้าเว็บ
ฟรี ไม่ต้องมีคีย์ มีเสียงไทย 2 ตัวคือ Premwadee (หญิง) และ Niwat (ชาย)
เป็นช่องทางที่ไม่ได้เปิดเป็นเอกสารทางการ วันหนึ่งอาจใช้ไม่ได้

**`gemini`** — โทนการเล่าดีกว่า สั่งอารมณ์การอ่านด้วยข้อความได้ ต้องมี API key

```bash
.venv\Scripts\pip install google-genai
setx GEMINI_API_KEY "คีย์ของคุณ"
```

แล้วแก้ `config.json` เป็น `"engine": "gemini"`

## ข้อควรระวังเรื่องลิขสิทธิ์

เครื่องมือนี้ทำขึ้นเพื่อฟังเนื้อหาด้วยตัวเองบนเครื่องตัวเอง แบบเดียวกับโปรแกรมอ่านหน้าจอ
**อย่านำไปเปิดเป็นบริการสาธารณะ และอย่าแจกจ่ายไฟล์เสียงที่สร้างจากงานที่มีลิขสิทธิ์**
เพราะเป็นการเผยแพร่งานของผู้อื่นซ้ำ ซึ่งผิดกฎหมาย
ผู้ใช้รับผิดชอบการใช้งานของตัวเอง
