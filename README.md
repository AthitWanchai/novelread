# novelread — เว็บฟังนิยายเสียง

ดึงเนื้อหานิยายจากหน้าเว็บ แกะเอาเฉพาะเนื้อเรื่อง แล้วอ่านออกเสียงด้วยเสียง Neural
ทำงานบนเครื่องตัวเอง ไม่ต้องสมัครสมาชิก ไม่ต้องมี API key

## ใช้ทำอะไร

วางลิงก์ตอนนิยาย → กดปุ่มเดียว → ฟังได้เลย พร้อมไฮไลต์ตามที่กำลังอ่าน
จำตำแหน่งที่ค้างไว้ และเก็บเสียงที่สร้างแล้วไว้ในเครื่อง ฟังซ้ำไม่ต้องโหลดใหม่

## เริ่มใช้งาน

ต้องมี Python 3.10 ขึ้นไปในเครื่อง จากนั้นดับเบิลคลิก:

```
start.bat
```

ครั้งแรกจะติดตั้งของที่จำเป็นให้เอง แล้วเปิดเบราว์เซอร์ที่ `http://127.0.0.1:8756`

ถ้าอยากสั่งเอง:

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python server.py
```

## ปุ่มลัด

| ปุ่ม | ทำอะไร |
|---|---|
| `Space` | เล่น / หยุด |
| `←` `→` | ย่อหน้าก่อนหน้า / ถัดไป |
| คลิกที่ย่อหน้า | กระโดดไปอ่านตรงนั้น |

## โครงสร้าง

```
server.py          เซิร์ฟเวอร์ + API
lib/fetcher.py     ดึงหน้าเว็บ (ทำฝั่งเซิร์ฟเวอร์เพราะเบราว์เซอร์ติด CORS)
lib/extractor.py   แกะเนื้อเรื่องออกจากโฆษณาและเมนู
lib/normalize.py   เกลาข้อความก่อนอ่าน เช่น แปลงเลขอารบิกเป็นคำอ่านไทย
lib/tts/           ชั้น adapter ของเครื่องเสียง สลับได้โดยไม่ต้องแก้โค้ดส่วนอื่น
public/            หน้าเว็บ
sites.json         กฎการแกะเนื้อหาแยกตามเว็บ
pronounce.json     พจนานุกรมคำอ่าน เติมเองได้
config.json        ตั้งค่าเสียง ความเร็ว พอร์ต
```

## ปรับให้เข้ากับเว็บที่อ่านประจำ

ถ้าเว็บไหนแกะเนื้อหาได้ไม่สะอาด (มีเมนูหรือโฆษณาปน) เพิ่มกฎลงใน `sites.json`:

```json
{
  "ชื่อเว็บ.com": {
    "title": "h1.chapter-title",
    "content": "div.chapter-content",
    "remove": [".ads", ".comment"],
    "next": "a.next-chapter"
  }
}
```

ถ้าไม่ได้ตั้งกฎไว้ ระบบจะใช้ตัวแกะอัตโนมัติ (trafilatura) ซึ่งใช้ได้กับเว็บส่วนใหญ่อยู่แล้ว

## แก้คำที่อ่านผิด

เจอคำไหนอ่านเพี้ยน โดยเฉพาะชื่อตัวละครนิยายแปล ใส่ลงใน `pronounce.json`:

```json
{
  "เย่เฉิน": "เย่ เฉิน",
  "Lv.": "เลเวล "
}
```

## เครื่องเสียง

**`edge` (ค่าเริ่มต้น)** — เสียง Neural ของ Microsoft ผ่านช่องทางที่ Edge ใช้อ่านออกเสียงหน้าเว็บ
ฟรี ไม่ต้องมีคีย์ มีเสียงไทย 2 ตัวคือ Premwadee (หญิง) และ Niwat (ชาย)
เป็นช่องทางที่ไม่ได้เปิดเป็นเอกสารทางการ วันหนึ่งอาจใช้ไม่ได้

**`gemini`** — โทนการเล่าดีกว่า สั่งอารมณ์การอ่านด้วยข้อความได้ ต้องมี API key

```bash
.venv\Scripts\pip install google-genai
setx GEMINI_API_KEY "คีย์ของคุณ"
```

แล้วแก้ `config.json` เป็น `"engine": "gemini"`

## ทดสอบ

เปิด `server.py` ค้างไว้ แล้วสั่ง:

```bash
.venv\Scripts\python test_pipeline.py
```

## ข้อควรระวังเรื่องลิขสิทธิ์

เครื่องมือนี้ทำขึ้นเพื่อฟังเนื้อหาด้วยตัวเองบนเครื่องตัวเอง แบบเดียวกับโปรแกรมอ่านหน้าจอ
**อย่านำไปเปิดเป็นบริการสาธารณะ และอย่าแจกจ่ายไฟล์เสียงที่สร้างจากงานที่มีลิขสิทธิ์**
เพราะเป็นการเผยแพร่งานของผู้อื่นซ้ำ ซึ่งผิดกฎหมาย
ผู้ใช้รับผิดชอบการใช้งานของตัวเอง

## สิ่งที่ยังทำได้อีก

- อ่านตอนถัดไปต่อเนื่องอัตโนมัติ
- ชั้นหนังสือเก็บเรื่องที่อ่านค้าง
- ส่งออกเป็น MP3 ไว้ฟังในรถ
- รองรับเว็บที่สร้างเนื้อหาด้วย JavaScript (ต้องใช้ Playwright)
- ตัดคำไทยด้วย pythainlp เพื่อคลี่ไม้ยมกให้ถูกต้อง
